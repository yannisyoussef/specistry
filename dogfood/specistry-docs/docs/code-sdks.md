---
title: Code samples and SDK mappings
description: Generate protocol examples without inventing an SDK API.
---

Specistry generates deterministic cURL, HTTP, JavaScript, TypeScript, Java, and Python request examples from canonical operations. Environment selection changes only the approved configured base URL, and credentials remain placeholders.

SDK examples are authored mappings. A mapping identifies a declared SDK and an operation, then supplies exact code inline or from a confined file. Specistry never guesses package names, client classes, or method signatures.

When a project has no SDK, omit `sdks`. The reader continues to show protocol examples and does not imply that a client library exists.
