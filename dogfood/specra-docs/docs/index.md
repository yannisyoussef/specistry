Specra compiles OpenAPI contracts, controlled Markdown or MDX, navigation, code samples, search, playground policy, versions, and quality findings into validated artifacts. A server-rendered reader consumes those artifacts without loading source contracts at request time.

Use this portal for the author and operator workflow. It is not the Specra marketing site.

## Choose a path

- [Install Specra](./installation) in an isolated consumer project.
- Follow the [quickstart](./quickstart) to build a documentation set.
- Review the [security model](./security) before enabling a playground or operating the reader.
- Read [compatibility and support](./compatibility-support) before adopting a release candidate.

<Callout type="warning" title="Release candidate">

Specra has not made a public software-license decision. The package and deployment workflow may be evaluated, but public distribution remains blocked until the owner selects and applies a license.

</Callout>
