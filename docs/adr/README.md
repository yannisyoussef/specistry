# Architecture decision records

ADRs record decisions that constrain multiple slices or security boundaries. Status is one of `PROPOSED`, `ACCEPTED`, `SUPERSEDED`, or `REJECTED`. Accepted records are immutable history: material changes create a superseding ADR and link both records.
